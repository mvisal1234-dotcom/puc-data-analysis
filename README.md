# PUC Data Analysis and Visualization

## Project Overview

This repository contains my Python environment setup, workshop exercises, and homework for the Data Analysis and Visualization course at Pannasastra University of Cambodia.

## Tools and Libraries

- Python 3.12
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- Plotly

## Homework

### Problem 1: Environment Report
A Python function that checks installed packages, displays their versions, and identifies missing packages.

### Problem 2: Safe Division
A Python function that handles division, numeric string conversion, and invalid inputs safely.

## How to Run

1. Install Python.
2. Create a virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Open `notebooks/00_setup.ipynb` in VS Code.
5. Select the Python environment and run the notebook cells.
